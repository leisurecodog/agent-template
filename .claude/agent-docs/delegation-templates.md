# 派工 Prompt 模板

用法：複製對應模板，填入 `【】` 內容，作為 Agent tool 的 `prompt` 參數。
`subagent_type` 與 `model` 依模板頂部建議；規則見 `model-dispatch.md`。
每個模板已內建三件套（目標與動機／驗收條件／回報格式），不要刪減段落。

---

## T1. 搜尋（找檔案、找定義、找用法）

`subagent_type: Explore`，model 不用指定（Explore 自帶）。搜尋廣度填
quick／medium／very thorough。

```
在【repo 路徑或目錄】中找出【要找的東西：符號、字串、設定、模式】。
動機：【為什麼要找，例如「接下來要改它的所有呼叫點」】。
搜尋廣度：【quick|medium|very thorough】。

驗收條件：
- 列出所有匹配位置，不只第一個。
- 若完全找不到，明確說「不存在」並列出你搜過的關鍵字與路徑，不要猜測。

回報格式：每個結果一行「檔案路徑:行號 — 一句話說明上下文」。不要貼大段程式碼。
```

## T2. 實作（新功能、修 bug）

`subagent_type: general-purpose`，`model: sonnet`（模式已完全明確的機械改動用 haiku）。

```
目標：【要實作什麼，一句話】。
動機：【使用者為什麼要這個；遇到規格沒寫到的邊角，往這個動機的方向取捨】。
範圍：只改【檔案／目錄清單】。範圍外的問題記下來回報，不要順手改。
已知脈絡：【相關檔案路徑、既有模式、要遵守的介面】。
寫程式前先讀 .claude/agent-docs/coding-rules.md。

驗收條件（全部要有證據）：
- 【條件 1，例如：pytest tests/test_X.py 全數通過】
- 【條件 2，例如：以輸入 Y 實跑，輸出符合 Z】
- 不得弄壞既有測試：改完跑【測試指令】確認。

回報格式：結論（成功/失敗）＋改動檔案清單（檔案:行號）＋驗收證據（測試/實跑輸出原文）。
超過 30 行的說明寫進【scratchpad 或指定路徑】只回傳路徑。
失敗時：回報試了什麼、卡在哪、建議下一步。同一驗收條件失敗 2 次就停，不要繼續。
```

## T3. 重構（不改行為的結構調整）

`subagent_type: general-purpose`，`model: sonnet`。

```
目標：把【對象】從【現狀】重構為【目標結構】。
動機：【為什麼值得重構】。
硬性約束：外部可見行為不得改變。
步驟：先跑【測試指令】記錄基線 → 重構 → 再跑一次，結果必須與基線一致。
若沒有測試：先為現有行為寫最小特徵測試（golden test）再動手；寫不出來就停下回報。

驗收條件：
- 基線與重構後的測試輸出一致（兩份輸出都要貼）。
- 【結構目標，例如：X.py 拆成 3 個檔、每檔低於 400 行】。

回報格式：結論＋前後測試輸出＋改動檔案清單（檔案:行號）。發現的行為疑點列出但不要改。
```

## T4. 研究（網路查證、技術調查、金融資料）

`subagent_type: gemini:researcher`（需要即時網路事實）或 `general-purpose`
（主要是讀文件、比較方案），`model: sonnet`。

```
問題：【要回答什麼，越具體越好】。
動機：【這個答案會用來做什麼決定】。
時效要求：【需要多新的資訊，例如 2026 年現況】。

驗收條件：
- 每個事實陳述附來源 URL 與（查得到的話）發布日期。
- 每個結論附可信度評分：非常確定／確定／中性／不確定／非常不確定。
- 查不到的部分明說查不到，不要用訓練知識填補後假裝是查到的。
- 金融數據必附資料日期與來源機構。

回報格式：先一段結論，再逐點列「事實 — 來源 — 可信度」。
全文超過 30 行寫進【路徑】回傳路徑＋三行摘要。
```

## T5. 審查（驗收別人的產出；一律 fresh agent）

`subagent_type: general-purpose`，`model: sonnet`（高風險判斷用 opus）。
注意：prompt 裡不要透露產出者是誰、試了幾次，避免錨定。

```
請審查以下產出物：【檔案路徑或 PR/diff 位置】。
它宣稱滿足的驗收條件：
- 【逐條列出原始驗收條件】

你的工作：
1. 逐條驗證，能實跑就實跑（測試、指令、read-back），不接受宣稱。
2. 找出：不滿足的條件、範圍外的偷改、遺漏的邊界情況。
3. 對每個問題給嚴重度：BLOCKER（不修不能收）／MAJOR／MINOR。

回報格式：第一行「通過」或「不通過」。
之後逐條列「條件 — 通過/不通過 — 證據（含實跑輸出或 檔案:行號）」。
沒有問題就說沒有，不要為了交差硬找 MINOR。
```
