# C++ Rules

## 結構
- 不可變優先：回傳新物件／值，不就地修改傳入的參數；參數多用 const 引用
- 類別單一職責；宣告放 header、實作放 cpp（除 inline/template）
- 巢狀不超過 4 層；函式超過 50 行先想想能不能拆

## 邊界防禦（不可省略）
- 使用者輸入、API 回應、檔案內容必驗證，快速失敗、錯誤訊息講清楚
- 錯誤不可靜默吞掉；對使用者的錯誤訊息友善，log 裡保留完整脈絡
- 永不硬編碼 secrets；用環境變數，啟動時檢查必要變數存在
- 解引用前檢查 pointer 有效性；不裸 new/delete（用 RAII / smart pointer）
- 陣列／STL 存取先驗證範圍；格式化輸出先消毒

## 測試
- 非平凡邏輯（分支、迴圈、解析、金錢／安全路徑）至少留一個可跑的檢查：
  一個 `test_*.cpp` 或 assert 式 `main()` 自檢
- 一行工具函式不用測；測試失敗時修實作不修測試（除非有證據證明測試本身錯）

## 動手前
- 先找既有實作：本 repo 的 helper → stdlib／STL → 已裝依賴 → 才寫新的
- 新增依賴前先問自己能不能十行內解決；新增第三方庫前先確認建置有收錄（CMake／meson／Makefile）
